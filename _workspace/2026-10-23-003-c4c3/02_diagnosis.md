# 진단

## 장르·레지스터

- 장르: 1,000자 이내 자기소개서 문항 답변(essay).
- 레지스터: 과거 경험을 서술하는 합쇼체. 문체와 전문용어는 보존한다.
- 사용자 초점: 하네스 조정과 개인 스킬 재사용을 한 문단 안에서 인과·진행 관계로 잇고, 마지막에 본인의 설계와 판단이 드러나도록 다듬는다.

## 겨냥 순서의 지배 패턴

1. **C-1 기계적 병렬 열거 — 두 번째 문단의 작업 나열.** 번호식 열거는 없지만, 하네스 조정 → Unity MCP 연결 → 추론 강도·모델 배분 → 개인 스킬 → 규칙 재사용 → 단계별 검토가 각각 완료 보고로 이어져 문단이 작업 목록처럼 읽힌다. 특히 “커밋·푸시·PR 절차는 개인 스킬로 정리하게 했습니다”가 앞선 하네스 조정과 따로 놓여, 본인이 정한 기준을 개인 스킬에 담아 다음 작업에 재사용했다는 관계가 약하다. 같은 기준을 어디에 적용했고 어떻게 남겼는지를 중심으로 묶는 것이 최우선이다. C-1의 명시적 번호식 시그니처에 해당하는 확정 판정이 아니라, 사용자 지적과 일치하는 구조적 가족 판정이다.

2. **E-1 문장 리듬의 균일성 — 비슷한 길이의 완료 보고 반복.** 16문장이 30~72자이고, 주로 40~60자대의 “~했습니다” 문장으로 경험을 차례차례 끊는다. 두 번째 문단은 6문장으로, 짧은 연결·설정·정리 보고와 긴 설정 나열이 교대하지만 생각의 흐름보다 작업 단위가 먼저 드러난다. 원인과 적용 관계가 있는 문장은 이어 쓰고, 본인의 검토·판단은 짧게 남겨 리듬을 바꿀 수 있다. 합쇼체 유지 자체를 E-2 오류로 취급하거나 억지로 종결형을 섞지 않는다.

3. **C-4 문단 첫 문장 요약 공식 — 결말의 역할 재요약.** 각 문단이 “개발하며 … 주도했습니다”, “이 기준이 … 조정했습니다”, “전투 연출에서는 … 바꿨습니다”, “그 결과 … 보완했습니다”로 내용을 먼저 요약한다. 자기소개서의 명료한 도입은 보존하되, 마지막 문단은 이미 설명한 플레이 흐름과 AI·본인의 분담을 다시 풀어 말해 힘이 분산된다. 전투 연출 사례에서 확인한 판단 기준을 최종 반영 결정으로 이어 마무리하면 본인의 설계와 책임이 더 또렷해진다. 이 역시 문서 구조에 대한 판정이며 결산 어휘 카운트 검출 결과와 구별한다.

## 정량 앵커와 판정 한계

- 입력 841자, risk_band low, score 0, route_hint light. 점수는 보조 근거이며 단독 AI 판정 근거가 아니다.
- v2.0 카운트형은 모두 0이다. A-7·A-8·A-9·A-16·A-18·A-19를 확정 근거로 삼을 수 없다. A-17은 hold이며 지배 패턴으로 지목하지 않는다.
- 결산·균형 카운트도 0, 연결어미 뒤 쉼표 비율 0이다. D-1·H-1·C-11을 억지로 적용할 이유가 없다.
- 쉼표 포함률·사용률 각 0.12, 한자어 명사화 밀도 0.005로 낮다. lexical_diversity 0.85(z=+3.91)는 문맥 확인용이며 수정 목표가 아니다. 추상명사 체인이나 대칭 대구는 지배적이지 않다.
- 문장 길이는 원문을 종결부호 뒤 공백으로 나누어 별도 확인했다. 위 E-1의 길이 범위는 이 관찰값이며, 표준편차나 인간·AI 구별을 확정하는 수치로 해석하지 않는다.

## 보존 지침

- 본인이 게임 규칙·기능 의존성·작업 범위·진행 순서를 정하고 결과를 검토했다는 주도권을 유지한다.
- 하네스와 개인 스킬은 반드시 한 문단으로 묶는다. 추론 강도, 반복 Unity 설정의 하위 모델 배분, 에이전트 수정 범위와 재귀 생성 제한, Unity MCP로 코드·씬·프리팹을 확인한 사실을 보존한다.
- 커밋·푸시·PR의 변경 범위 확인, 기존 작성 양식, 팀원 리뷰 요청을 개인 스킬의 재사용 기준으로 연결한다. 개인 스킬을 본인이 직접 작성했다는 식으로 사실을 바꾸지 않는다.
- 전투 판정·연출 분리, 카메라 포커싱·히트스톱의 단계적 적용, 직접 플레이 후 흔들림·타이밍 조정은 유지한다.
- 생산성 수치, 수상·성과, 새로운 기술적 이유나 동기, 확인되지 않은 사용자 반응을 추가하지 않는다. 마지막은 규칙과 플레이 의도에 맞는지 검증하고 최종 반영을 판단한 본인의 역할로 닫는다.
